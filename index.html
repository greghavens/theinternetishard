02 / THE HOME OF PROTOMIRE

One model.
Its whole lifecycle.

Protomire is a model-development IDE built on Code – OSS. Bring research, datasets, training recipes, evaluation, and exports together in one project.

A native MCP server gives agents access to the same operations as the human workbench. Build your recipe, track the runs, and keep the model’s history connected.
