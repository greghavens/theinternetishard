THE PROJECT, IN PRACTICE

What you can do with it.

01

What this repository contains

Quantizes language-model linear layers while preserving the vision tower, embeddings, and output head in BF16. Includes the MTP weights; the model card documents measured tradeoffs and runtime limits. This is a quantization of Qwen’s model, not an original base model.

02

Choose the right runtime

Model formats are not interchangeable. Match the published artifact to the runtime, architecture support, and available memory documented in its card.

03

Inspect provenance

The model card identifies the base model, derivation, and license terms. A quantized build remains a derivative of its upstream model.
