THE PROJECT, IN PRACTICE

What you can do with it.

01

Fine-tuning recipe

QLoRA training on the pi_agent split of Fable-5 traces targets agentic behavior and tool use.

02

Published weight formats

Choose among LoRA, BF16, GGUF, NVFP4, and MLX artifacts for different research and runtime paths.

03

Compare with the base

The evaluation harness reports differences against the base across instruction-following, reasoning, coding, and function-calling benchmarks.

FROM IDEA TO USE

How it works.

  1. 01

    Choose a format

    Match the model artifact to the runtime and hardware you intend to use.

  2. 02

    Inspect the model card

    Review architecture requirements, provenance, and licensing before download.

  3. 03

    Run and evaluate

    Use the documented serving path and compare results for your own workloads.

One model family, several formats
LoRA     Apply the fine-tune delta
BF16     Full-precision merged weights
GGUF     Compatible llama.cpp / LM Studio
NVFP4    NVIDIA Blackwell serving
MLX      Apple Silicon workflows

Runtime support and memory requirements differ. See each artifact’s model card.
