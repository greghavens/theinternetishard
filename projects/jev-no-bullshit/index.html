Jev No Bullshit

For anyone who wants an assistant’s completion report to distinguish verified work, failures, and unfinished tasks.

A PROJECT BY GREG HAVENS

THE PROJECT, IN PRACTICE

What you can do with it.

01

Catch unverified claims

Look for statements such as “all tests pass” when the session provides no matching evidence.

02

Make uncertainty explicit

Flag weasel words that soften a claim without explaining what was checked.

03

Surface omitted failures

Detect summaries that leave out a failed command or unfinished step while presenting the overall work as complete.

04

Ask for a grounded correction

When a summary fails the check, the assistant receives specific feedback and can verify the work or correct its report.

FROM IDEA TO USE

How it works.

  1. 01

    Configure Jev

    Install the plugin for your assistant and supply a TypeSafe API key through its documented configuration.

  2. 02

    Work normally

    The check runs when the assistant produces its final summary.

  3. 03

    Review the correction

    Flagged claims are returned to the assistant with reasons tied to the session evidence.

The kind of claim it checks
Assistant: “All tests are passing.”

Session evidence: no test command was run.

Feedback: Verify the claim against recorded actions,
or state plainly that tests were not run.

Illustrative example. A model-based check is not a guarantee that every incorrect claim will be detected.
