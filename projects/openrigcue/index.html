OpenRigCue

One place to control a motion platform, tactile feedback, and rig accessories across supported racing and flight games.

A PROJECT BY GREG HAVENS

THE PROJECT, IN PRACTICE

What you can do with it.

01

Read game telemetry

Detect supported racing and flight games and collect telemetry over UDP, shared memory, named pipes, and other game-specific interfaces.

02

Drive motion platforms

Configure motion cueing, smoothing, shaping, and autotuning for supported platform controllers.

03

Feel every detail

Send effects to multichannel bass shakers and control wind, LEDs, belt tensioners, and other accessories.

04

Compensate for VR motion

Use SteamVR and OpenXR components to support motion compensation while the rig moves.

FROM GAME TO RIG

How it works.

  1. 01

    Download and launch

    Use the Linux x86-64 AppImage or build from source, then open the desktop or browser interface.

  2. 02

    Connect the game

    Use native telemetry when available, or the Proton bridge for supported Windows games.

  3. 03

    Tune your hardware

    Configure motion, shakers, and accessories for the rig and game you use.

Launch the Linux AppImage
chmod +x openrigcue-x86_64.AppImage
./openrigcue-x86_64.AppImage

The desktop window needs GTK 3 and WebKitGTK 4.1. See the release and README for dependencies and source-build instructions.

TAKE IT FOR A SPIN

Start here.

Download the Linux x86-64 AppImage. Check the hardware and game lists before connecting a rig.

EARLY SOFTWARE / SAFETY

Expect bugs. Keep your motion platform's emergency stop within reach on first use. The browser interface has no authentication; run it only on a trusted network. The v0.2.0 release notes say it had not yet been tested on real motion, wind, shaker, or belt hardware.
