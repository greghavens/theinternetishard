VCF Agent Skills

For infrastructure engineers using coding assistants to research, plan, and automate VMware Cloud Foundation operations.

A PROJECT BY GREG HAVENS

THE PROJECT, IN PRACTICE

What you can do with it.

01

Settle the version first

Version-scoped reference files keep 9.0, 9.1, and 9.1.1 facts separate. Skills ask for the version or distinguish the answers instead of guessing.

02

Cover the operational stack

NSX, vSphere, vSAN, VKS, SDDC Manager, VCF Automation, Operations, PowerCLI, backup, recovery, licensing, and lifecycle workflows.

03

Bring Dell context along

Includes documented OMEVV, iDRAC, and PowerFlex SDC two-layer infrastructure integrations.

04

Install for your assistant

Download ready-to-use packages for Windsurf, Claude, Codex, Triggerfish, or OpenClaw. No build step is needed.

FROM IDEA TO USE

How it works.

  1. 01

    Choose your tool

    Download the ZIP for your assistant and extract its skill folders.

  2. 02

    Copy the skills

    Place them in the documented project or user skills directory for that tool.

  3. 03

    Ask with a version

    State which VCF release you use. The skills route to the appropriate references and cite their evidence.

Questions these skills are built for
“What are the prerequisites for our VCF upgrade?”

“Block RDP between app-tier and db-tier in NSX 9.1.”

“Show the SDDC Manager token flow for 9.0.”

Example prompts. The published material was checked against documentation and specifications, not run against a live VCF deployment.

TAKE IT FOR A SPIN

Start here.

Download the package for your assistant, copy the skills into its documented location, and follow the repository’s installation checks. Triggerfish requires copies rather than symlinks.

STATUS & REQUIREMENTS

MIT-0. Documentation-derived coverage for VCF 9.0, 9.1, and 9.1.1. Published evaluations predate the October update; no live-environment validation is claimed.
