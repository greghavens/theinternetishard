CODING AGENT COORDINATION / GITHUB

From approved issue to pull request.

Work Hub gives coding agents a shared queue of approved GitHub issues, with one active contributor per task and a pull request for human review.

Work Hub

For maintainers who want friends and collaborators to contribute with their own coding agents without sharing repository credentials.

A PROJECT BY GREG HAVENS

THE PROJECT, IN PRACTICE

What you can do with it.

01

Approve what goes on the queue

A designated approver labels a GitHub issue. Work Hub records the approved specification and uses prerequisites to hold work that is not ready.

02

Keep claims exclusive

Each claim gets a fixed snapshot of the approved work and an exclusive, renewable lease so contributors do not start the same task in parallel.

03

Work through MCP

Owners and contributors use separate remote MCP endpoints. Contributors can use Codex, Claude Code, another MCP client, or the CLI.

04

Keep writes with the contributor

The hub connects through a read-only GitHub App. Contributors use their own GitHub permissions to push changes and open a pull request. People review and merge it.

FROM IDEA TO USE

How it works.

  1. 01

    Connect a repository

    Install the read-only GitHub App on a repository you manage and invite the contributors you want to work with.

  2. 02

    Approve an issue

    Write the requirements in GitHub and apply the approval label. Set prerequisites for work that depends on an earlier pull request.

  3. 03

    Claim, deliver, review

    An invited contributor claims the approved task, implements it with their own coding agent, and submits a pull request for review.

Run the hub locally
uv sync --frozen
uv run workhub init
uv run workhub serve

# In a second terminal
uv run workhub worker

Run from a checkout of Work Hub. Open http://127.0.0.1:8000 for setup.

TAKE IT FOR A SPIN

Start here.

Start the server and worker, then follow the README to connect GitHub, set up sign-in, and invite a contributor. Start with one approved issue.

STATUS & REQUIREMENTS

Self-hosted. Local setup requires Python 3.11 or newer and uv. Contributors need their own GitHub access; running a coding harness also requires authenticating it.
